Make a routine as clear to build and inspect as a path: readable steps, visible choices, bounded repeats, and an obvious shared continuation.

Requested outcome

The owner wants substantial Routine work that matches the liked main editor. Historical autonomous examples motivate four runtime capabilities: ending a path early, choosing the next paths, generating a path during execution, and adjusting drive velocities. The immediate implementation improves the actual editor and audits those contracts; it does not turn old placeholders into executable robot behavior.

Direction

Reuse the editor’s neutral chrome, spacing, inspector, menus and control primitives. Make branch ownership, preview choices, repetition and reconvergence readable where they occur. Keep local insertion destinations explicit and preserve keyboard navigation, undo and saved source.

Scope and boundaries

  • RoutineWorkspace, RoutinePanel and RoutineInspector: flow hierarchy, insertion, selection, preview and clear empty/problem states.
  • Audit the real authoring, serialization, preview and runtime boundaries for the four capabilities. Preserve generated and unsupported saved data until explicit edits.
  • Existing branch/repeat source semantics remain authoritative. AQU LabVIEW execution is deferred; Routines stay local and saving never connects a robot.
  • Continue the unfinished waypoint optimizer closeout. Preserve its exact accepted trajectories and legacy validation. The owner subsequently authorized the next beta release after verification. No live robot or native installer operation is included.

Current work

Design-led implementation, capability audit and independent source/visual reviews are complete. The final branch passed both hosted CI runs and merged through PR #85; beta.17 platform packaging and publication are running.

Acceptance and verification

  • A populated branch and nested repeat clearly show their scope and continuation; choose preview routes without editing robot logic.
  • Insertion destinations and row selection are predictable; keyboard navigation, Escape focus return, undo and exact save/reload remain working.
  • Inspect 1440×900 and 1100×720 with inspector open/closed, long labels, both unit systems, empty/missing/disabled states.
  • Run focused behavior tests and relevant native pointer/keyboard workflows, then typecheck, full tests, built smoke and renderer gate on the final state.
  • Obtain independent read-only source and visual review. Report failed gates as failures. Bundle ceilings remain unchanged without owner approval.
