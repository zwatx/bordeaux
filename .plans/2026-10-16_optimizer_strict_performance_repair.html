Speed up the production optimizer by removing repeated bookkeeping and geometry derivation, while preserving its exact strict search and validation.

Intent and decision

The owner requested repair after the provisional-screen experiment preserved quality but missed its cost gate. This new authorization supersedes the previous finite experiment's no-tuning boundary. Its negative results remain unchanged. The direct repair accelerates the existing strict optimizer; it does not enable an inaccurate heuristic or claim a twofold improvement.

The earlier all-phase screen lost real strict improvements and changed later search centers. Pattern-only screening recovered the three exposed cases but avoided only one or two strict calls, with no convincing twofold headroom. GPT-6 Astra's read-only diagnosis recommends exact-work elimination first. The private estimator remains inactive.

Focused implementation

effectiveRanges now resolves waypoint arrivals only for waypoint-anchored ranges. Empty, fraction and distance ranges no longer serialize every dense sample coordinate. Turn-boundary detection returns immediately when no stationary turns exist. The reachability adapter shares the identical canonical path state it previously built twice.

Within one strict refinement, dense validation geometry is derived once. Each local retiming still remaps its new velocity profile and runs the full physical validator. Refinement, job and input boundaries remain separate; there is no global cache or reused validation verdict. The public dense-validation API is unchanged.

Safety and measurement contract

Strict baseline selection, candidate order, local sibling settlement, normal timing, material-gain threshold, densities, sample ceilings, refinement/recovery rules, topology, gates, footprint and clearance checks remain unchanged. Work ceilings stay 24/48/72; cooperative budgets and external worker deadlines remain unchanged. Checkpoints never apply themselves. Applied artifacts and BDX retain independent exact validation.

Regression tests first demonstrated 4,104 unnecessary formatting calls for non-waypoint ranges, 12 for no-turn timing, and three identical highest-density derivations during real retiming. The repaired tests require zero unnecessary formatting, one derivation per refinement density, and fresh validation arrays for every retimed profile. The retiming input is the actual historical strict slalom trial 9, executed against current source, not a recorded result substituted for execution.

The final comparison runs serial A1/B1/B2/A2 for fixed 24-work and real five-second budgets on all three exposed corpus cases, with no warmup and no concurrent heavy work. Controls use the pre-edit compiled snapshot. Every final result and published checkpoint must match exactly under fixed work. Independent neutral, corridor, accepted-artifact and BDX checks run outside the online search timer. Useful-result targets derive from contemporaneous controls, including actual nonzero baseline publication. Two observations per variant are a bounded directional measurement, not statistical or universal evidence.
