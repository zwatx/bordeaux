Accepted direction

Drawing and editing are roughly 75% of use, with frequent iterations and pushes. Workbench’s direct controls combine with Strip’s bottom properties and timeline. Invalid timing never locks geometry editing. Stopped waypoints allow independent tangents.

The top bar reads project, Paths / Routines / Settings, editing actions, robot destination and exact-scope Push. Chrome and selection are neutral. Cards, decorative left stripes, blue Push styling and playful navigation icons are removed from the rebuilt surfaces.

Explicit Save refreshes Paths/*.bdx for Git sharing. Background and departure saves preserve source only. Saving never opens a robot connection. Offline IP setup and explicit missing-directory creation preserve the separate connection, review and acknowledged Push boundaries; selective Push never silently becomes Push all.
